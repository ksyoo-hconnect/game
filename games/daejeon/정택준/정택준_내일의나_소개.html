OVERVIEW

게임 개요

장르생활 어드벤처. 방 안의 물건을 눌러 이야기를 진행
무대집(진료 전) · 병원(진료 준비 활용) · 집(진료 후 생활과 계획) · 다음 진료
조작물건 탭, 추천 문장 선택. 오토 모드로 자동 진행(1·2·4배속)도 가능
핵심 장치진료 가방. 집에서 남긴 질문과 이야기가 병원에서 그대로 다시 나온다
엔딩집 → 병원 → 집 한 바퀴. 나선에 바퀴가 쌓이고 방의 화분이 자란다
PROLOGUE

도입: 기록 없이 방문했던 날

게임은 앱이 없던 때의 진료부터 보여준다. 같은 질문을 다시 받았을 때의 차이를 직접 겪게 하는 구성이다.

기록 없이 방문했던 날
  • "언제부터 불편하셨어요?"에 답하지 못함
  • 집에서 떠올린 질문이 바쁜 하루에 흐려짐
  • 다음 방문에서도 같은 아쉬움 반복
인바이츠루프로 준비한 날
  • 같은 질문에 내가 남긴 기록을 보며 답함
  • 집에서 담은 진료 가방이 진료실에서 열림
  • 진료 내용이 집으로 이어짐

플레이 흐름

진료 전 · 집발견·질문검진표·생활 기록·일기장에서 궁금한 것을 찾아 질문으로 남김
병원 · 준비이어보기키오스크에서 앱 연결 코드로 준비 내용을 이어받고 달라진 점을 보완
진료 후 · 집생활과 계획계획표 확인, 실천 목표 선택, 어려웠던 점 기록
다음 진료다시 보기지난 기록을 이어 확인. 나선에 한 바퀴가 더 쌓임
OBJECTS

기능을 물건으로

메뉴 이름 대신 방 안의 물건을 누른다. 물건 하나가 V5 기능 하나다.

📋검진표검진 결과와 이전 검사값 변화 확인
👟운동화 · 생활 기록걸음·수면·혈압 기록 확인
📔내 일기장수치에 없는 불편함·생활 변화 기록
🗓️진료 일정예정된 진료와 준비할 내용 확인
🗒️나의 계획하기로 한 계획 확인, 실천 목표 선택
🧭건강 좌표과거·지금·앞으로의 나를 함께 보기
🖥️병원 키오스크앱 준비 내용 이어받기, 공용 화면 정리
👜진료 가방진료에서 이야기할 내용 모음
PRINCIPLES

게임에서 익히는 원칙

장면사용자가 익히는 것
일기장진료 준비에 넣을 내용과 내 기록에만 둘 내용을 직접 구분한다
공유 범위 확인개인 대화 전체가 아니라 진료 준비에 넣은 내용만 진료에서 보인다
검진표수치 변화는 보여주되 원인과 진단은 진료에서 확인한다
키오스크입력 → 저장 → 의료진 검토목록 반영 → 검토는 서로 다른 단계다. 사용 후 공용 화면을 정리한다
건강 좌표"아침 시간이라면?" 같은 조건 비교는 실제 계획 변경이 아니다. 변경은 요청 후 검토로 반영한다
설정글씨 크기와 설명 방식은 내가 편한 대로 바꾼다. 사실과 계획은 바뀌지 않는다
