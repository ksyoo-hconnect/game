스토리의 핵심

지켜보던 AI가, 챙김받는 사람이 되기까지

  1. 사용자 = AI사용자는 한 사람을 지켜보는 AI

    플레이어는 푸어의 휴대폰 속 AI입니다. 재검 미루기, 약 건너뛰기, 새벽 치킨. 봐줄지 단호하게 말할지 대화로 고릅니다.

  2. 푸어 = 흐트러진 사람푸어는 숨기고, 미루고, 무너진다

    어떻게 대답하든 푸어는 결국 쓰러집니다. 봐주면 미루고, 단호하면 숨깁니다. 가슴 답답한 거 몇 주 됐는데 말 안 했어. AI는 보여준 것밖에 볼 수 없었습니다.

  3. 회귀 · 세 유령신들의 학교에서 다시 눈을 뜬다

    건강의 여신 히기에이아가 푸어를 수호자 학교로 데려갑니다. 과거·현재·미래의 유령이 무엇을 숨겼고, 지금 누가 화면 너머에서 그를 돌보고 있었는지 보여줍니다. 그리고 이번에는, 네가 돌볼 자다.

  4. 빙의 · 환생푸어가 LOOP로 다시 태어난다

    시간을 되감고(회귀), 휴대폰 속으로 들어가고(빙의), 이름이 POOR에서 LOOP로 뒤집힙니다(환생). 숨기다 무너져 본 사람이, 이제 챙기는 AI가 됩니다.

  5. LOOP = 우리를 챙기는 AILOOP가 사용자를 챙기러 온다

    잠금화면에 LOOP의 알림이 뜹니다. 야, 나 기억나? 자기가 숨겨서 무너졌던 경험이 있기에 LOOP는 말합니다. 나 그때 말 안 해서 그렇게 됐잖아. 너는 다 연결하자.

핵심 대비

POOR와 LOOP

POOR

  • 보여준 것만 보고, 숨긴 건 모른다
  • 봐주면 미루고, 다그치면 숨긴다
  • 사용자가 보든 말든 요청을 보내다 음소거된다

LOOP

  • 연결해 준 만큼 먼저 알아챈다
  • 사용자가 들을 수 있는 순간에 말을 건다
  • 왜 필요한지 대화로 설명하고 허락을 구한다
